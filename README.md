# Amber Run

Законченный раннер на TypeScript, Vite и Canvas 2D. Вся графика рисуется программно, звук синтезируется Web Audio. Внешние картинки, шрифты, сервисы и игровой движок не нужны.

## Быстрый запуск

Репозиторий хранит исходники игры; папка `outputs` и готовый `Amber Run.html` в Git не хранятся.

Требуется Node.js 22.18+ и pnpm. В каталоге проекта:

```sh
pnpm install
pnpm dev
```

Откройте локальный адрес, который напечатает Vite.

## Разработка

Проверки, сборка и локальный предпросмотр:

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm build` создаёт `dist/index.html` для статического хостинга и `dist/Amber Run.html` — автономную версию со встроенными скриптом и стилями. Папка `dist/` добавлена в `.gitignore`, поэтому после клонирования репозитория её ещё нет.

`dist/Amber Run.html` можно открыть напрямую в современном браузере после сборки. Он работает без интернета. Рекорд хранится в браузере; в приватном режиме и при ограничениях на локальные файлы сохранение может быть недоступно. Для стабильного сохранения используйте локальный сервер или обычный хостинг.

## Управление

- Пробел, ↑, клик или касание игровой сцены — прыжок.
- Быстро отпустите для короткого прыжка; удерживайте для высокого.
- Esc, P или кнопка паузы — пауза/продолжение.
- После столкновения нажмите «Ещё раз».
- Звук включается только после действия пользователя; настройка сохраняется локально.
- При потере фокуса, уходе со вкладки или изменении размера окна забег ставится на паузу.

## Устройство

- `src/physics.ts`: физика с шагом 1/120 секунды, буфер 120 мс, допуск после схода 80 мс, уменьшенные коллайдеры, безопасные интервалы и рекорд. Дорожка ровная, поэтому сход с края в обычном забеге не возникает.
- `src/scene.ts`: пять слоёв параллакса, оригинальные рисунки персонажа и объектов, свет, пыль и анимация.
- `src/audio.ts`: синтез звуков прыжка, приземления, столкновения и тихого атмосферного аккорда.
- `src/main.ts`: игровой цикл, ввод, интерфейс, пауза и перезапуск.
- `tests/physics.test.ts`: проверки существенного поведения.

## Что проверено

TypeScript и production-сборка проходят. 11 автоматических тестов: высота короткого/длинного прыжка, очень быстрый клик между шагами, 30/60/144 кадров/с, буфер перед приземлением, допуск после схода, отсутствие автопрыжков от удержания, предел скорости и безопасные интервалы, проходимость всех типов препятствий при скоростях от 300 до 570, коллизии, сброс состояния, сохранение и ошибки хранилища.

В браузере проверены старт, прыжок с клавиатуры, клик, пауза в воздухе, продолжение, столкновение, экран результата, перезапуск, сохранение рекорда после перезагрузки, переключатель звука, компоновка 1280×800 и 390×844. Физический телефон и качество звучания на реальных динамиках не проверялись. Встроенный браузер не воспроизвёл обычную смену активной вкладки, поэтому автоматическая пауза по visibilitychange/blur подтверждена кодом, но не этим UI-тестом. Необязательные WebMCP-инструменты включаются лишь в поддерживающих их браузерах; среда проверки их не предоставила.
